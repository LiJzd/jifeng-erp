# 经典工作台复刻记录

## 入口与覆盖范围

Frappe Desk 的“集沣生产协作”工作区新增“经典业务工作台”快捷入口，路由为 `jifeng-legacy`。页面复刻参考旧系统的顶部品牌栏、模块侧栏、可关闭标签页、主页快捷入口和分组功能卡片，覆盖物料、材料、产品、订单、生产、人事、工资、模具、版种、发镀、外发、销售、财务、总经理、权限、日志、全屏、插件、工具和关于等导航。

物料、材料、产品、订单、生产、人事、工资、模具、版种、发镀、外发、销售、财务、权限和日志模块现有“正式业务”分组，打开 ERPNext/Frappe 原生采购、库存、生产、员工、工资、委外、报价、零售、销售、财务、用户及日志单据，或集沣同步订单、商品工艺档案、流程单、计薪记录、成本试算、模具档案、版种档案、员工补充档案。已确认同名的数据入口（仓库、供应商、客户、产品档案、人事档案、模具录入与查询、版种录入与查询）也直接打开对应服务器档案。正式入口受 Frappe 原生权限控制；未映射的旧系统复刻页面仍为本地交互预览。正式入口只证明单据可访问，不代表旧系统同名流程已完成映射或验收。

尚在本地预览的常见业务表单包括生产指令单和费用登记。物料/材料的申购、入库、出库、调拨、盘点入口分别新建原生采购申请、采购收货、发料、移库、盘点凭证；库存与明细查询进入正式库存报表。旧订单录入/查询进入 ERPNext Sales Order，前台开单进入 POS Invoice；收款/付款凭证入口已改为新建 ERPNext Payment Entry 并预设收付类型，同名查询入口进入按收付类型筛选的原生单据列表。工资录入/明细/审核入口已改为正式计薪记录；工资汇总指向 HRMS Salary Slip。预览列表提供日期和关键词筛选、指定日期、分页、行编辑、删除、审核状态、CSV 导入导出；预览表单提供明细行、词典查找、图片选择与清空、打印预览和本地保存。

## 本地预览边界

- 未映射预览页新增、编辑、审核、删除和导入的数据保存在当前浏览器的 `localStorage`，不会调用 ERPNext 业务接口，也不会改动生产凭证。
- 旧系统中的客户、仓库、员工、商品、库存和单据数据没有复制。词典弹窗展示空表，输入关键词后可将其作为本地预览值带回表单。
- 图片选择只保留文件名供预览；没有上传服务，也不把图片文件写入 ERPNext。
- CSV 文件在浏览器本地解析；导出内容来自本工作台的本地预览记录。
- 插件和远程协助入口保留说明，没有启动下载或安装外部程序。
- 页面角色沿用现有生产协作工作区的 Stock Manager、Manufacturing Manager 和 System Manager 范围。

## 浏览器页面勘察补充

对照登录后的旧系统逐项打开了模块入口和重点功能页面，并记录了可见的字段、状态筛选、视图切换和工具按钮。工作台曾为物料申购、生产计划图片、模具录入、外发加工、销售入库和报价单补上对应的专属表单或列表操作；其中模具录入现已改为正式档案入口。其余预览操作日志使用时间范围筛选，调前台和调订单从本地草稿中选择并带入明细。

旧系统有些表格位于画布或异步嵌入区域，浏览器中无法读出明细列的完整内容；因此这些列按可见字段和同类业务表单补齐，不把猜测的数据结构当作旧系统原始数据。未映射预览页中的图片和附件只保存文件名；正式模具档案使用 Frappe 附件。远程工具与权限受限入口保留说明，不复制生产数据，也不下载外部程序。
