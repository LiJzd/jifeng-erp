# 录音需求落实与验收

依据：用户提供的《标准录音 189》转写；分享页只作背景。用户已明确选择“先只做试算，不自动入账”。

| 录音问题 | 当前实现 | 验收方式 |
|---|---|---|
| 每天两套系统重复录单 | 聚水潭订单游标增量导入；按商家/环境/内部订单号唯一保存；订单明细生成流程单 | 同一页重复同步不重复建单；源数量变化标记待核对 |
| 手工销售订单与生产流程脱节 | 已提交的 ERPNext Sales Order 按勾选明细生成流程单，保存明细来源、定制要求、包装和附件快照；源单修改或取消标记待核对 | 重复生成复用原流程单；源变更不覆盖计划与人工要求；取消后阻止新采购申请 |
| 图片、规格和商品档案手工建 | SKU 查询创建 Item、商品映射、商品工艺档案；从订单补查未建档SKU | 同一SKU只对应一个映射；已有同码人工 Item 不被接管 |
| 图片按商品编码归档 | 可信图片域名可配置；后台下载、校验图片并以SKU命名保存为 File | 限域名、HTTPS、图片格式和大小；链接变更后旧下载不覆盖新来源 |
| 供应商货号挤占工艺字段 | 商品工艺档案独立供应商货号、供应商字段；工序明细有独立工序/加工商/单件费；另保存旧号、分类、设计记录、专利、参考价和重量等旧页面字段 | 用商品编码、供应商货号或旧号检索档案；工序按行顺序展示；参考价不覆盖订单成交价 |
| 新款/定制与包装要求散落群文件 | 来源订单、商品默认要求、流程单各自保存要求；附文件并显式下发到流程单 | 再次同步保留人工要求；流程单可打印图片、物料与工序 |
| 每单做物料分析、查看库存、按单采购 | 商品档案可读取已提交 BOM；流程单保存独立用量/单价快照；查看物料库存并生成采购申请草稿 | 多次点击复用已生成草稿；仓库按用户权限过滤 |
| 生产流程单与正式工单脱节 | 流程单记录生产 BOM，可生成同公司同商品、已提交且启用 BOM 的 ERPNext Work Order 草稿；正式工单反向记录流程单 | 重复生成复用未取消工单；公司、商品、BOM、销售订单明细一致；提交和发料由 ERPNext 原生校验 |
| 相同商品不同订单价格不同 | 各流程单保存独立材料/加工费用；试算读取本单费用 | 修改模板不会自动改变历史流程单 |
| 分批、返工、损耗、后补加工费难算 | 试算区分首次回货、返工回货、待检处理，按数量状态转移 | 100件→50合格+50返工→48合格+2损耗；材料不重复累计 |
| 按流程单汇总收回费用 | 标准委外收货明细增加流程单关联；流程单汇总已提交明细的材料、加工、其他费及退货冲减；成本试算单可确认带入汇总费用并重算各批 | 草稿/已取消凭证不计；跨公司和商品错误关联被拒绝；无已提交收货明细时不改费用 |
| 回货数量二次录入 | 试算单可读取有权限的已提交委外收货明细；按接收、拒收、工艺损耗合计带入回货数量，保留来源单及明细；工艺损耗先带入，其余先列待检供人工分类 | 重复读取不追加同一来源行；手工同号批次跳过；保存时核对来源数量、公司、商品和流程单，损耗不少于凭证已确认量；已取消或已退货来源须人工核对后重新录入 |

## 业务口径

- 同步源价格保存为来源信息；不把聚水潭销售单价当作材料成本。
- 试算分母为计划数量减已确认损耗。返工、待检、尚未回货仍视为预计可合格数量，因此未结清时只是预计成本。
- 实际委外凭证费用单独汇总供核对，不悄悄替换已有回货批次的试算费用。
- 读取正式回货批次只填写未保存的试算表格，首次/返工类型与合格、返工、待检数量由操作者核对；有委外退货时暂不自动带入批次，需按净回货手工处理。此限制不影响正式凭证费用的退货净额汇总。
- 采购申请按物料分析全量生成草稿。实际库存、预计库存会展示；采购员核对在途和已占用库存后调整草稿。
- 录音中“144”的单位名称和换算未得到可靠确认。保留SKU原单位；在 ERPNext 的 UOM 和 Item 换算表按公司实际口径配置，不猜测重量与数量换算。
- 钉钉来源没有提供表格/字段约定。本版有要求录入与附件入口，未接入未指定的钉钉文档。

## 尚需现场验收

服务器主机、站点和凭据配置路径；商家 co_id、实际授权类型、平台订单覆盖范围；真实SKU/订单字段和图片域名；物料单位换算、历史档案导入；生产人员权限。上述信息不会通过聊天正文收集密钥。
